# Гофермарт — накопительная система лояльности

HTTP-сервис для учёта бонусных баллов пользователей интернет-магазина «Гофермарт». Пользователи регистрируют номера заказов, система начисляет баллы через внешний акруал-сервис, баллы можно списывать в счёт оплаты новых заказов.

## Стек

- **Go 1.26**
- **PostgreSQL** — ббаза данных
- **chi** — HTTP-роутер
- **pgx/v5** — драйвер PostgreSQL
- **golang-migrate** — миграции БД
- **JWT** — аутентификация
- **bcrypt** — хэширование паролей
- **cleanenv** — конфигурация из YAML и переменных окружения

## Архитектура

```
cmd/gophermart/
internal/
  api/                — HTTP-хэндлеры
  service/            — бизнес-логика
  repository/         — запросы к БД
  models/             — доменные модели и ошибки
  worker/accrual/     — фоновый обработчик начислений
  clients/accrual-system/ — клиент внешнего сервиса(accrual)
  auth/               — JWT
  config/             — конфигурация
  storage/postgresql/ — пул соединений, миграции
migrations/           — SQL-миграции
config/config.yaml    — конфигурация по умолчанию
```

Accrual воркер работает по схеме pipeline:
**Generator** (заказы из БД) → **Workers** (запросы к внешнему сервису) → **Flusher** (батч-запись в БД)

## Конфигурация

Поддерживаются три способа (приоритет: флаг > переменная окружения > config.yaml):

| Параметр | Флаг | Переменная окружения | YAML-ключ |
|---|---|---|---|
| Адрес сервера | `-a` | `RUN_ADDRESS` | `http_server.address` |
| DSN базы данных | `-d` | `DATABASE_URI` | `db.dsn` |
| Адрес акруал-сервиса | `-r` | `ACCRUAL_SYSTEM_ADDRESS` | `accrual_system.address` |
| Секретный ключ JWT | — | `AUTH_SECRET_KEY` | `auth.secret_key` |

## Запуск

```bash
# С конфиг-файлом
go run ./cmd/gophermart/

# С флагами
go run ./cmd/gophermart/ -a localhost:8080 -d "postgres://..." -r http://localhost:8081
```

Миграции запускаются автоматически при старте сервиса.

## API

Все защищённые эндпоинты требуют заголовок `Authorization: Bearer <token>`.

### Регистрация

```
POST /api/user/register
Content-Type: application/json

{
"login": "user", 
"password": "secret"
}
```

| Код | Описание |
|---|---|
| 200 | Успешно, токен в заголовке `Authorization` |
| 400 | Неверный формат запроса |
| 409 | Логин уже занят |

### Аутентификация

```
POST /api/user/login
Content-Type: application/json

{
  "login": "user", 
  "password": "secret"
}
```

| Код | Описание |
|---|---|
| 200 | Успешно, токен в заголовке `Authorization` |
| 400 | Неверный формат запроса |
| 401 | Неверный логин или пароль |

### Загрузка номера заказа

```
POST /api/user/orders
Content-Type: text/plain

12345678903
```

| Код | Описание |
|---|---|
| 200 | Заказ уже был загружен этим пользователем |
| 202 | Новый заказ принят в обработку |
| 400 | Неверный формат запроса |
| 409 | Заказ загружен другим пользователем |
| 422 | Неверный номер заказа (алгоритм Луна) |

### Список заказов

```
GET /api/user/orders
```

| Код | Описание        |
|---|-----------------|
| 200 | Список заказов  |
| 204 | Заказов нет     |

Пример ответа:
```json
[
  {
    "number": "9278923470",
    "status": "PROCESSED", 
    "accrual": 500, 
    "uploaded_at": "2020-12-10T15:15:45+03:00"
  },
  {
    "number": "12345678903",
    "status": "PROCESSING", 
    "uploaded_at": "2020-12-10T15:12:01+03:00"
  }
]
```

Статусы: `NEW` → `PROCESSING` → `PROCESSED` / `INVALID`

### Баланс

```
GET /api/user/balance
```

Пример ответа:
```json
{
  "current": 500.5, 
  "withdrawn": 42
}
```

### Списание баллов

```
POST /api/user/balance/withdraw
Content-Type: application/json

{
"order": "2377225624", 
"sum": 751
}
```

| Код | Описание |
|---|---|
| 200 | Успешно |
| 402 | Недостаточно средств |
| 422 | Неверный номер заказа |

### История списаний

```
GET /api/user/withdrawals
```

| Код | Описание         |
|---|------------------|
| 200 | Список списаний  |
| 204 | Списаний нет     |

Пример ответа:
```json
[
  {
    "order": "2377225624", 
    "sum": 500, 
    "processed_at": "2020-12-09T16:09:57+03:00"
  }
]
```
